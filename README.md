# მომხმარებელთა მიმართვების დამუშავება

## სტატუსი

- ნაწილი 1 — გასუფთავება და ანალიზი: შესრულებულია
- ნაწილი 2 — ვალუტის კონვერტაცია (NBG API): მიმდინარე
- ნაწილი 3 — LLM კლასიფიკაცია: მიმდინარე
- ნაწილი 4 — შედეგი და დოკუმენტაცია: მიმდინარე

## დაყენება და გაშვება

საჭიროა Python 3.10+.

```bash
python -m venv venv
venv\Scripts\activate        # Linux/macOS: source venv/bin/activate
pip install -r requirements.txt
python main.py               # ან: python main.py path/to/requests.json
```

შედეგები იქმნება `output/` საქაღალდეში:

- `processed.json` — გასუფთავებული მიმართვები;
- `rejected.json` — გამორიცხული ჩანაწერები (`record` — ორიგინალი, `reasons` — მიზეზები);
- `summary.json` — სტატისტიკა და გასწორებების ჟურნალი (`corrections`).

## პროექტის სტრუქტურა

```
main.py            გაშვების წერტილი
src/cleaning.py    ველების ვალიდაცია და გასწორება
src/analysis.py    სტატისტიკა
```

## მონაცემების გასუფთავება: გადაწყვეტილებები

ყოველი ჩანაწერის ყველა ველი მოწმდება დამოუკიდებლად, ასე რომ ერთ ჩანაწერს
შეიძლება რამდენიმე გამორიცხვის მიზეზი ჰქონდეს. ყველა გასწორება ფიქსირდება
`summary.json`-ის `corrections` ველში (`from` → `to`), რათა ცვლილება გამჭვირვალე იყოს.

### გასწორებული ჩანაწერები

**REQ-005** — თარიღი `14/02/2026` → `2026-02-14`
- საქართველოში მიღებულია ფორმატი DD/MM/YYYY.
- 14 თვე ვერ იქნება, ამიტომ ორაზროვნება არ არის.

**REQ-006** — თანხა `"3 200,00"` (ტექსტი) → `3200.0`
- სივრცე ათასების გამყოფია, მძიმე — ათწილადის (ევროპული ჩაწერა).

**REQ-009** — ვალუტა `gel` → `GEL`
- განსხვავება მხოლოდ რეგისტრშია.

**REQ-012** — თარიღი `2026.04.02` → `2026-04-02`
- წელი პირველ ადგილზეა, ამიტომ რიგი YYYY.MM.DD სტანდარტულია.

**REQ-018** — თარიღი `5 მაისი 2026` → `2026-05-05`
- ქართული თვის სახელი ცალსახად ითარგმნება.

**REQ-019** — ვალუტა `$` → `USD`
- სიმბოლო ცალსახად აღნიშნავს დოლარს.

**REQ-027** — თანხა `"350 ლარი"`, ვალუტა `null` → `350.0`, `GEL`
- ვალუტა თანხის ტექსტშივე წერია.
- თუ ის `currency` ველს ეწინააღმდეგება, ჩანაწერი გამოირიცხება.

### გამორიცხული ჩანაწერები

**REQ-011** — თანხა არ არის მითითებული
- თანხის გამოგონება შეუძლებელია.
- 0-ით ჩანაცვლება სტატისტიკას დაამახინჯებდა.

**REQ-015** — ტექსტი ცარიელია
- მიმართვის შინაარსი უცნობია, ამიტომ კლასიფიკაცია შეუძლებელია.

**REQ-022 (მეორე ეგზემპლარი)** — იდენტური დუბლიკატი
- პირველი ეგზემპლარი რჩება, მეორე გამოირიცხება, რომ ორჯერ არ დაითვალოს.

**REQ-024** — თანხა `-500`
- უარყოფითი თანხა მიმართვისთვის აზრს მოკლებულია.
- ნიშანი შეიძლება შეცდომით იყოს, მაგრამ ამის დადგენა ვერ ხერხდება.

**REQ-030** — თარიღი `2026-13-05`
- მე-13 თვე არ არსებობს.
- შესაძლოა ეს იყოს YYYY-DD-MM (13 მაისი), მაგრამ ეს მხოლოდ ვარაუდია
  და დანარჩენი ჩანაწერების ფორმატს ეწინააღმდეგება.

### სხვა გადაწყვეტილებები

- **თანხა 0** ვალიდურად ითვლება: ინფორმაციის მოთხოვნას ან საჩივარს ხშირად თანხა არ აქვს.
- **საშუალო თანხა** ითვლება ვალუტების მიხედვით ცალ-ცალკე, რადგან ნაწილ 1-ში
  ჯერ კონვერტაცია არ არის და GEL/USD/EUR-ის შერევა არასწორი იქნებოდა.
  მოცემულია ორი მაჩვენებელი: ყველა ჩანაწერით (`average`) და მხოლოდ 0-ზე მეტი თანხით
  (`average_nonzero`), რადგან 0-იანი მიმართვები საშუალოს ხელოვნურად ამცირებს.
- **REQ-023** ფაილში არ არის (id-ების რიგში ნახტომია). ეს არ ითვლება შეცდომად —
  დაკარგულ ჩანაწერს ვერ აღვადგენთ.
- `channel` და `text` ნორმალიზდება (პატარა ასოები, ზედმეტი სივრცეების მოშორება).
